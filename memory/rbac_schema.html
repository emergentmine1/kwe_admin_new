Proposed view: v_user_effective_permissions

Returns active users' effective permissions through assigned active roles. The view is a retrieval convenience; it does not enforce authorization.

CREATE VIEW v_user_effective_permissions AS SELECT u.accountid, u.useremail, u.username, r.code AS rolecode, p.code AS permissioncode, p.function, p.action FROM pf_users u JOIN pf_userroles ur ON ur.accountid = u.accountid JOIN md_roles r ON r.code = ur.rolecode JOIN pf_rolepermissions rp ON rp.rolecode = r.code JOIN md_permissions p ON p.code = rp.permissioncode WHERE u.status = TRUE AND r.status = TRUE AND p.status = TRUE;

A user may receive the same permission through multiple roles; consumers can use DISTINCT or aggregate as required.
